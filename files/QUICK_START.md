## 💻 Customization (5 Minutes)

### Edit Your Salon Name
Find this line in `index.html`:
```html
<div class="text-2xl font-playfair text-gold tracking-wider">AURA</div>
```
Replace `AURA` with your salon name.

### Edit Your Contact Info
Find and update:
```jsx
Phone: +1 (555) 123-4567          → Your phone
Email: hello@auraluxe.com          → Your email
Address: 123 Luxury Lane           → Your address
Hours: Monday - Friday: 9AM - 8PM  → Your hours
```

### Change Colors (Gold Theme)
Find this in the `<style>` section:
```css
--gold: #D4AF37;     /* Change this hex to your brand color */
--black: #090909;
--dark-gray: #111111;
```

### Update Images
Replace Unsplash image URLs with your own:
```jsx
src="https://images.unsplash.com/photo-..."
```

## 🎓 How to Edit Code Safely

If you're comfortable with HTML/CSS:

1. **Edit Colors** → Find `:root` in `<style>`
2. **Edit Text** → Search for the text you want to change
3. **Edit Images** → Replace the `src="https://..."` URL
4. **Edit Animations** → Find `animate`, `transition` sections
5. **Test Changes** → Refresh browser with Ctrl+R (Windows) or Cmd+R (Mac)

## 🆘 Troubleshooting

**Website looks broken?**
- Make sure you're using a modern browser
- Clear browser cache (Ctrl+Shift+Delete)
- Try a different browser

**Images not showing?**
- Check internet connection
- Right-click image → Copy image URL
- Make sure URL is correct

**Want to add more content?**
- Copy and paste existing sections
- Change the text and images
- Test to make sure it works
